Implied value is this radar's own claim from the snapshot, not a prediction that a token will launch, or when. “Records no token” means the snapshot carries no market cap, CoinGecko id or symbol for it — not proof that none exists.

How the value is worked out

Every row is scored by the same formula, impliedValue in lib/model.ts. Nothing is special-cased by name.

  1. Base. TVL × 0.32 — the size of the protocol, in dollars.
  2. Growth. The 7-day TVL change, clamped to −50% … +150%, weighted 0.6: fast growers score higher, shrinking ones lower.
  3. Maturity. Older listings with no token recorded earn more weight, rising from 0.55 toward 1.00 over four years; an unknown listing date counts as 270 days.
  4. Breadth. +3% per extra chain, up to five — a protocol live on many chains is harder to ignore.
  5. Category. A durability factor per category (1.00 for Dexs and Lending, down to 0.85 for bridges and wrapped products that mirror a token already trading).

Farm plans are built from the same record: capital is sized to TVL ($75–$500 a position), the hold period to age (45–90 days), and the core action to the protocol's category and main chain. Every step states what it costs and how long it takes.
